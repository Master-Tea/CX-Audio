# CX Audio 1.4.3

优化低延迟模式在 Wi-Fi、笔记本及浏览器批量到包时的断续播放。

- 修复普通到包批次被误当积压丢弃的问题，以及丢积压时清除抗抖动余量、导致不断欠载的循环。
- 按实际到包间隔和批次大小提前调整缓冲。基础目标保持 USB 6 ms / 无线 30 ms；自适应目标最多 USB 24 ms / 无线 80 ms。稳定 10 秒后逐步回落，不把临时安全余量一直保留。
- HTTP 浏览器兼容模式优先使用 512 帧回调，降低主线程调度压力；Worklet 保持音频线程渲染。
- 时钟校正对缓冲的包周期波动做平滑处理，更快跟随播放设备与发送端的时钟偏差，减少长时间播放后缓冲耗尽或堆积。
- 长断流恢复后在下一次渲染统一修剪旧音频，避免重播大量积压；维持有限缓冲上限。
- 更新播放器资源版本，升级后刷新接收页面即可获取新播放引擎。

验证：实际渲染器的 23 项测试覆盖 44.1 / 48 / 96 kHz、10 / 15 / 45 ms 批量交付、±1000 ppm 时钟偏差、临时缓冲回落和断流恢复。复现用的每 45 ms 集中到包场景中，旧版 Worklet 与兼容模式在 8 秒模拟内各欠载 166 次；新版两者均为 0 次欠载、0 次误剪积压。该结果是确定性模拟，不能替代真实网络和扬声器听感验收。

抖动时会适度增加延迟以维持连续播放；超出有限保护预算的网络中断仍会中断声音。本版不宣称新的端到端声学延迟测量结果。

MSIX 版本 1.4.3.0，沿用既有签名，可直接升级。高级模式本地端点静音、恢复与虚拟设备名称逻辑保持兼容。
