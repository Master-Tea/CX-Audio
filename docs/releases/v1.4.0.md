# CX Audio 1.4.0

侧边栏新增“虚拟扬声器（高级）”。普通模式允许电脑本地与网络接收设备同时播放；高级模式将声音送入 VB-CABLE 虚拟播放设备，禁用其余 Windows 播放端点，供网络 / USB 接收设备播放。

- 提供官方虚拟音频驱动安装入口，校验固定 SHA256、Windows 数字签名和发布者。首次安装需管理员授权，在 VB-CABLE 安装器中点击 Install Driver，并按提示重启电脑。
- 高级模式将默认、媒体、通信输出固定到虚拟设备，采集不回退到物理输出。暂停串流或接收端断开时，本地输出继续禁用；设备状态持续检查。
- 切回普通模式或退出时恢复原设备与各类默认输出。设备修改前持久化恢复记录，独立守护进程处理主进程异常退出；未完成的恢复可重试。
- 整合当前工作区的低延迟分包、播放器缓冲调整与后台保活改动。低延迟档的 USB / 无线目标和端到端测量限制详见 README。
- 修复发布目录可能保留旧 XAML 编译资源的问题，确保新侧边栏和页面随 ZIP 一起发布。

使用方法：解压 ZIP 后运行 CXAudioOutput.exe，或运行随附的 Install-CXAudio.ps1 安装 MSIX；进入“虚拟扬声器（高级）”，安装驱动、刷新设备、启用高级模式。点击“恢复普通模式”恢复电脑本地声音。

VB-CABLE 是 VB-Audio / Vincent Burel 的第三方 Donationware，按其许可使用；驱动不包含在 CX Audio 的 ZIP / MSIX 中。安装页：https://vb-audio.com/Cable/ 。MSIX 延用既有 MasterTea 签名证书，指纹为 4C800525ACB48750E0B613F0A1EA4AD3D719A476。

隔离范围为 Windows 播放端点。热插拔到检查生效之间存在短暂窗口，其他管理员程序或绕过 Windows 音频引擎的驱动也可能改变结果，因此无法承诺硬件级绝对零发声；需要这一保证时应同时断开或关闭物理扬声器。

验证包括路由事务模拟测试、真实驱动安装程序签名校验、实际独立守护进程的退出恢复检查、只读 WASAPI 设备枚举、原生页面回归和网页播放器测试。自动化检查不安装驱动、不修改测试电脑的真实音频设备；真实驱动隔离和手机声学播放仍需在目标电脑验收。
