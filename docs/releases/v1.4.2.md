# CX Audio 1.4.2

修复高级虚拟扬声器模式启用后其他程序仍可能从电脑扬声器播放的问题。

- 用 Windows Audio 端点静音保护替代将设备可见性变化当作全局无声证明的做法；对其他活动输出持续重新应用静音，并将默认、媒体、通信输出固定到虚拟设备。
- 在修改静音前保存恢复记录；切回普通模式、退出或异常恢复时还原原静音状态及默认输出。原本静音的设备保持原状态；兼容恢复旧版本的设备禁用记录。
- 虚拟播放设备使用 CX Audio 作为显示名，保留 VB-Audio 驱动身份、签名和许可说明。通过可编辑的 Windows 播放端点标签改名，无需为改名提权。
- 统一剩余的 CX Audio Output 产品文字及维护脚本中的窗口标题。
- 增加独立进程读取实际静音状态、默认输出和虚拟设备名称的验证工具。
- 补充 Microsoft Store 上架评估，说明第三方驱动、管理员操作、隐私政策、包身份、签名及审核测试要求。

软件静音仍有边界：独占模式、绕过 Windows 音频引擎的驱动，以及新设备/其他程序取消静音到保护重新生效之间的窗口，不能用普通用户态应用承诺硬件级绝对无声。需要这一保证时应关闭物理扬声器。

MSIX 侧载版本为 1.4.2.2，沿用原有签名，可直接升级。商店构建需使用 Partner Center 身份和第四段为 0 的版本号，并完成独立审核准备。
