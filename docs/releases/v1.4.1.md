# CX Audio 1.4.1

修复 MSIX 安装后点击启动立即退出的问题。此前安装包缺少 Windows App SDK 自包含组件的 WinRT 类注册，WinUI 初始化返回“类未注册”（0x80040154），导致窗口创建前崩溃；便携版使用不同的激活机制，未受这一问题影响。

- 打包时从项目实际还原的 SDK 组件合并官方 package.appxfragment，包含 WinUI、资源管理等组件的激活注册。
- 缺少关键类注册时中止打包，防止再次生成无法启动的安装包。
- 正式版本增加持久化启动和未处理异常日志，写入用户可写的日志目录。
- 发布脚本从应用清单读取 MSIX 完整版本号，避免产物文件名和包内版本不一致。

已在本机从 1.4.0 升级并通过 Windows 应用入口启动，确认真实安装版主窗口、首页导航和音频服务启动成功。现有应用数据和虚拟扬声器功能保留。

MSIX 版本为 1.4.1.1（高于诊断升级包 1.4.1.0），沿用原有 MasterTea 签名。直接安装新版即可升级，无需卸载或重新安装音频驱动。
